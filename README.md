# Insurance Policy Renewal Prediction System

Predicts which policyholders are likely to lapse, so insurers can run retention campaigns early.

## Modules
1. Authentication & Role Management (done)
2. Policyholder Data Management
3. Renewal Prediction Engine
4. Retention Campaign Service
5. Analytics Dashboard

## Tech Stack
Python, Flask, SQLAlchemy, SQLite, JWT

## How to run
    python -m venv venv
    venv\Scripts\activate
    pip install -r requirements.txt
    python app.py
